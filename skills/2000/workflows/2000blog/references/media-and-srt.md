# 音訊、逐字稿與影片圖片

## 工具與媒體取得

使用執行時真正可用的工具。2026-11-02 建技能時 PATH 可見 ffmpeg／ffprobe，未見獨立 yt-dlp 命令；此為盤點，不代表已完成下載或已配置語音辨識。必要時檢查 Python 模組或既有技能提供的下載／轉錄工具；不要宣稱任何特定 ASR 已可用。

1. 優先使用使用者提供的完整原檔；比對內容、總長、片頭片尾和上架版是否一致。素材不一致會讓 SRT 及截圖時間失準。
2. 取得本次確認影片的音訊、最高可用原封面、可供擷取畫格的影片；以video ID命名或放入該ID目錄，避免同名影片混檔。保存下載資訊及來源網址，不保存認證資訊。
3. 影片工具可處理所需功能時優先使用。使用 yt-dlp 等 CLI 時只針對確認影片並禁用播放清單；遇驗證／權限障礙可改用 Studio 正常下載 UI 或請使用者提供原檔，不抽取 cookies 或繞過限制。
4. 下載後以 ffprobe 核對影片及音訊時長、音軌、解碼正常；封面必須開圖確認非錯誤頁或低畫質占位圖。不將猜測的 maxres URL 當作已成功下載。
5. 所有產物保存在工作目錄；工具不在 PATH 時先找既有已知位置／工具依賴，不自行搜尋整顆磁碟或安裝大型環境。

## 完整音訊轉錄

使用環境既有的本機 ASR 或已授權的轉錄工具，先讀其技能或工具說明。`media-use` 在有合適既有轉錄管線時可用，但本任務不需要建立影片、HyperFrames composition 或重新渲染整支影片。未公開影片若只能用外部服務轉錄，先確認使用者對該服務與該媒體傳輸的授權。

- 依工具需求從完整音軌製作衍生 WAV，常見為16kHz單聲道PCM；保留原檔，不能只截取某段後忘記還原。
- 對長片按工具限制分段、保留每段起始秒數；可用接縫重疊降低漏詞，但合併時去除重複並加回偏移，不能各段從0秒接成假全片。
- 保存工具原始轉錄後再校訂繁體、名稱、英文車型與金額。字幕用全片原始時間軸，不能把片頭廣告長度直接扣掉。
- 全片讀取校訂稿；聽開頭、結尾、接縫及所有疑點，核對同步與重要數字。保固、價格、性能等口述錯誤仍按原話保存，文章另做查核和註明。
- 對照片長檢視所有較大空白區段，分辨無語音、音樂或漏轉。報告實際範圍與未辨識區，不以尾端時間接近片長作為唯一「完整」證據。
- 用 `txttosrt/scripts/srt_tools.py validate` 檢查最終SRT；時間碼格式、連續編號、非空文字、起訖時間、順序、媒體時長內有效範圍都要驗證。合併或重新對齊後不要求與原SRT逐段相同，但必須解釋變動並檢查同步。

## 按文章論點選圖

先完成大綱、定位時間，再從本機確認的影片擷取。可用 ffmpeg 的一格擷取；以下為指令形狀，執行時以實際檔名與已核實時間替換，所有路徑單獨引號保護：

```powershell
ffmpeg -ss 00:03:39.000 -i 'video.mp4' -frames:v 1 'chapter-03-00-03-39.png'
```

這只是截圖，不改影片或聲音，不需要影音創作框架。原始畫格留存，另產生網站用WebP／JPEG；如需縮小保留長寬比，不放大超過來源畫質。圖片合適尺寸依網站實際版型與原影片解析度決定，UX參照的1280×720不是硬性要求。

`image-map.csv` 一圖一列，至少包含：

```text
chapter,filename,video_id,timestamp,visible_content,alt,caption,media_id,media_url
```

從每章真正談到的內容找畫面，例如配備章展示該配備、空間章展示座椅／行李廂、行情章可用影片出現的價錢圖卡。若原影片根本沒圖卡，不做出假的影片數據截圖。擷取後開圖檢視，錯幀回到前後時間挑選；每張圖片的說明與對應章節都須回查。
