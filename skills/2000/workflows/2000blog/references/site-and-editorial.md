## 兩千的書面聲音

與 `youtube-channel-intelligence` 的 `references/2000car-writing-style.md` 一致；需要更貼近歷史文稿時再讀該參照，不強制把口播腳本格式套進部落格。

- 以中古車商與買家顧問角度解釋事情：價格、折舊、車況、維修成本、保值與使用情境。
- 楔子用一個矛盾或疑問建立閱讀理由；章節依原因、證據、代價與選擇展開，最後給明確判斷。
- 語氣直接、有經驗、能聊天，段落適合閱讀；保留必要反問與幽默，不把口播的每句招呼與贅字全搬進文章。
- 數字出現後解釋對一般買家的影響。區分新車原價、選配落地價、刊登價、成交價、車主期望價；折舊計算必須基準一致。
- 車型規格分清年式、世代、台灣版／海外版、原廠標配／前車主加裝；車主單一經驗不能寫成全車系通病。
- 個人經驗與引號內原話須回到 SRT。可以整理解釋，不編故事、不假裝親歷、不讓其他人說過的話變成兩千的話。
- 有效的結尾包含推薦的適用條件與限制；不用固定句型、誇張保證或過量導購。

## 文章包的實際欄位

`seo.json` 至少記錄以下有實際用途的內容，未能寫入者另記原因：

```json
{
  "title": "文章大標題",
  "slug": "本篇唯一且有意義的slug",
  "excerpt": "文章摘要",
  "focus_keyword": "核心查詢",
  "seo_title": "符合搜尋意圖的標題",
  "meta_description": "自然說明本文解答及價值",
  "categories": [],
  "primary_category": null,
  "tags": [],
  "featured_image_file": "cover.webp",
  "social_title": "分享標題",
  "social_description": "分享說明",
  "social_image_file": "cover.webp",
  "schema_type": "BlogPosting",
  "internal_links": [],
  "external_sources": [],
  "unapplied_fields": []
}
```

這是填寫契約，不是可直接送往 WordPress 的 API payload。不能因 JSON 有值就算後台已儲存。

SEO標題與描述以編輯器的實際預覽及可讀性校正，不以固定字數保證不截斷。slug沿用當時網站語言與結構，不擅改 permalink 設定。精選圖與社群圖先使用原影片封面，預覽裁切不佳再從同片選合適實際畫格，保留來源。

## WordPress 驗收重點

- 文章名稱由標題欄提供；正文不可再有 h1。4～5個主章及以「結論：具體結論」命名的結尾均在正文，圖片與文字不錯章。結尾用兩千直接分享的口吻，不以「兩千的話」作標題。
- 用內容編輯器支援的貼入方式；HTML 模式貼 HTML，視覺模式貼可保留格式的內容。不要把 Markdown 標記原樣貼成正文。
- 先上傳圖取得媒體 URL，再把本機路徑替換成真正 URL；確保沒留下 `D:\`、檔案占位字或空 img src。WordPress媒體庫對應的 alt／caption 及正文圖片也需核對。
- 檢查桌機與手機預覽，圖不變形、長表格可讀、影片可載入。只用編輯器實際提供的預覽／響應式功能，不靠猜網址。
- 草稿的「公開可見度」與「已發佈」是不同欄位；必須確認**狀態＝草稿**。不因可見度顯示公開就擅改權限，也不因按鈕 ID 叫 publish 就認為該點擊安全。
- 儲存完成後核對分類、標籤、精選圖、摘要及 Rank Math 值，預覽無誤才回報草稿完成；外掛分數不是驗收的唯一依據。
