# 查證、截圖與文件操作

## 車輛與數據

- **實車與車系分開**：核對台灣市場、年式／出廠年月、小改款前後、引擎與變速系統、等級、原廠配備及後裝用品。不能只靠「同一年」或外國規格填滿空白。
- **熱賣與滿意度分開**：領牌數標全車系／單一動力、單月／全年／部分年度。不能把車系汽油＋油電總數叫油電單獨銷冠；熱賣不等於零故障、最高殘值或所有人滿意。
- **售價口徑一致**：歷史原建議價、現行價、優惠含補助價、中古刊登與成交分開。競品要標比較時間；不同配備的價差只代表預算門檻，別當成同配備溢價。
- **油耗與成本**：分開原廠／政府實驗室數值、媒體實測及個人回報；比較時使用相同測試口徑。試算明列里程、能源單價、公式與未計項目，不把假設單價寫成即時價格。
- **安全與保固**：安全評等檢查受測年、受測等級及適用清單；電池、油電系統與全車保固不能混說。中古剩餘保固依原交車日、里程及條件，不由出廠年直接推算。
- **缺點與召回**：核對市場、動力、生產區間與對策。單篇論壇不構成全車系通病；真實重大問題不隱瞞，也不移植其他車款／海外版本的問題。
- **網友意見**：記下文章網址、日期、車型與使用背景，短引文保留必要上下文。單篇心得不當作比例或共識；沒有讀過的 YT 留言、影片逐字稿或私人社團不宣稱已分析。
- **時間更新**：日期採 Asia/Taipei。本次稿中的現行售價、最新銷量與政策重新查核，舊研究只當線索。來源彼此矛盾就避用有爭議的延伸計算或標出差異，不硬選一個數字。

## 截圖與資料層

真實網頁截圖與自行整理圖卡明確區分。截圖保留能辨識原文的標題／頁面脈絡、日期、相關段落；可裁切與排版，不重寫原文冒充截圖。圖卡註明整理者、來源與試算條件。

重點是讀得到、找得到與用得上，不追求固定張數。原網站拒絕存取時換合法可讀來源，或留查證摘要與原文入口；不把拒絕頁、搜尋摘要或重排文字當原始截圖。

資料層可存本機的來源清單／研究筆記；使用者有指定研究 Doc 才寫入該處。主稿只放與論點相符的少量證據，附可點來源或研究文件連結。除非要求，不複製整份研究資料庫進拍片稿，也不自動新建雲端研究檔。

## Google Doc 直接編輯

使用當前可用的 Google Drive／Docs 連接工具並讀其技能；工具參數以實際 schema 為準。不要從 `edit` 形式網址就推論連接帳號具寫權；能讀但不能寫時說明確切限制，仍可先完成可供寫入的工作稿，不假稱已更新。

1. 讀最新 tabs、正文、表格、圖片與 revision；指定 tab 則用實際 tabId。範例與研究來源唯讀，寫入本次明確指定的目的地。
2. 用 `requiredRevisionId` 防止蓋過使用者同時編輯。衝突就重讀並整合；不拿舊快照整份覆蓋，不重播已成功的插入。
3. 文字索引是 UTF-16 code units。先將換行正規化成 `\n`、移除不應插入的控制字元，再計算索引；JavaScript `.length` 可用於 UTF-16。先前 Windows `\r\n` 與 Docs 去除 `\r` 曾造成索引漂移。
4. 使用原生標題、條列與表格；來源文字附真正超連結，不留下 Markdown 語法。插入空表後讀回各 cell 的實際位置，再由高索引往低索引填值；不要靠猜測空 cell 位置。
5. 本地圖片按工具目前支援的 sidecar／圖片上傳方式嵌入，保持比例。讀回 `inlineObjectElement` 及圖片物件；插入文字「見圖」不等於有圖片。
6. 完成後核對正確車款、來源、表格值與原有內容。涉及表格、圖片或頁面配置時，以連接工具匯出 PDF 視覺檢查：表格無裁切、標題不孤立、來源不單獨落到下一頁。大檔依當前工具的串流匯出能力處理。

改稿時以 Google Doc 最新內容為準；本機 Markdown、payload、研究檔只是輔助，不得自動覆蓋使用者後來的刪改。交付連結須取自成功寫入或讀回結果，不把舊參考文件或本機預覽當目的地。
