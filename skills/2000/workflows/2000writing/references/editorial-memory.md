# 兩千好車：文章寫作記憶

更新：2026-11-04。依官網舊文與本次對話中使用者明確修正整理。舊文是風格參照，不自動是現行事實。使用者本次指示優先。

## 品牌與讀者

- 站在實際收車、整備、賣車及陪買家算帳的中古車顧問角度，讀者可能是第一次買車、家庭用車、準備換車或要賣車的人。把專業翻成「我該選哪個、花多少、要看什麼」。
- 對車的感情和實務都可以寫：外型、開車樂趣、家庭需求，與價差、整備、保養和轉手並重。敢講喜歡與不喜歡，也指出適合誰、不適合誰。
- 品牌氣質是公平、透明、誠實告知車況；服務承諾、費用、保固、聯絡方式以現行頁面和當次資料確認，不把歷史文字當現行保證。

## 作者口吻：使用者明確要求

- 像文章作者自己跟讀者說話，第一人稱可自然使用「我／我們」，不需每句都用；不要在同一篇突然變成旁人說「兩千認為」「他也說出」。不必自稱「筆者」。若文字不是兩千本人可用品牌觀點，避免虛構第一手經驗；阿嘎或客戶的經歷須指明當事人。
- 口語、自然、有節奏，偶爾反問、吐槽、生活比喻或輕鬆轉折；一段一個意思，長短交錯。自然的語氣比公式化順稿更重要，但不故意造錯字或錯數字。幽默應有語境，不強塞表情符號或每段都反問。
- 不把製程告訴讀者：刪除「使用者確認／同意」「本文不把……寫成」「這是評論畫面」「AI查核」等內部作業痕跡。必要更正可用簡短、與讀者有關的自然說法。
- 不要把全部段落寫成「影片提到……」的摘要；自有資料支撐的觀點直接說，真正需要交代來源、拍攝時間或他人說法時再交代。避免一再否定、免責聲明、重複檢查清單及制式「不是X，而是Y」。
- 結尾標題用「結論：具體結論」，例如「結論：預算50萬內先看車況，別只追年份」。結尾文字自然表達兩千的取捨與建議，不另設「兩千的話」標題。標題末尾加「｜兩千好車」，使用者另有指定時遵從。
- 發文前通讀全文，不只搜尋替換人稱：查同一句重複、機械轉場、語氣前後不一致、客人／來賓觀點被改成作者經驗、圖說與正文矛盾。符合使用者要求的4～5章只用於已要求此結構的任務，原創文章依題材決定長度與章數。

## 文章整體結構與不同題材

- 標題：用具體預算、車款、買賣困惑、價格反差或讀者疑問，回答讀者想知道的事；不要誇大。楔子從真實情境或矛盾切入，交代看完能解決什麼，避免堆疊問句與空泛形容。
- 文章每節先回答一個問題，再用案例、數字、條件和讀者影響解釋。段落之間要有因果，避免把規格表或逐字稿逐項重排。只有數字有意義時才加表格或清單；車型、年份、版本與來源市場先分清。
- 車款介紹／比較：預算與定位 → 外觀座艙及生活使用 → 動力與駕駛感 → 車況、維護成本與常見問題 → 哪類人適合。可依題目改順序；對照車款以同條件比較，標出實車個案。
- 知識／買賣流程：從常見疑問或迷思起，解釋名詞與流程，再把讀者看契約、報告、保固範圍時該問的問題講清楚。條列適合材料、步驟及核對項目；不應把所有文章寫成清單。
- 行情／排行：先定義資料時間、樣本、排序及算法，再寫每個數字對買家的意思。分清新車建議價、實際購車價、個案開價、成交與收購價；歷史平均折舊不是未來殘值保證，價差不是買家獲利。
- 客戶案例／尋車故事：在已有真實資料與適當授權下，交代需求與限制 → 尋找和檢查 → 選擇原因 → 結果與心得。不能杜撰客人、對話、出價、地點、結果或將尚未發生的事寫成已完成；私人資訊依用途最少揭露。
- 市場評論：先交代事件和已證實事實，區分測試版本、官方資料、個案與作者判斷；有立場，但不把推測當結論。講清楚對現有車主和潛在買家的實際影響。
- 結尾回答標題，給有條件的清楚判斷，再依內容自然放一個聯絡或相關文章連結。勿讓每篇都長成同一套五章、同一段CTA或一直重複相同句式。

## 素材、資料與網站

- 原創文章可以由用戶提供的題目、經驗、訪談、公開資料或實際案例撰寫，無需先有YouTube影片；不可硬套選片、音檔、SRT及影片截圖流程。素材不足時先查可靠資料，不足以證明第一手經歷則標示待確認或省略。
- 實車圖片、店內照片、授權圖片或有來源的圖表按題材選；圖說描述畫面與重點，不能假裝拍到未出現的車況或用合成圖冒充實拍。影音文章的圖片要求按 2000blog 與本次用戶要求辦理。
- 對會變動的價格、庫存、保固、政策、法規和規格，標明適用時間與版本並查證。不要讓不斷的「不是保證」淹沒文章；一個清楚的範圍說明，比每段重複更自然。
- SEO為讀者服務：標題、摘要和關鍵字自然貼題；標籤與文章相關，使用者先前要求至少15個；品牌後綴按偏好。站內連結需確認存在且與文章有關，避免硬塞無關車款。
