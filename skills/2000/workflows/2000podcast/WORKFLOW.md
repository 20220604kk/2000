## 先確定本集狀態

沿用對話中已確認的集數、資料夾、草稿、標題、人名、裁切與輸出方式，不重問。預設草稿 `ep<集數>`，原始媒體在 `<MEDIA_ROOT>\PODCAST\01-已播出\<集數>`；使用者另指定時優先。

先讀 [來源與參考](references/sources.md)，盤點實際檔案、原生草稿版本及已有工作紀錄。根據實際人物確認A/B，不能以C0001或軌號猜機位。已有進度先驗證並續作，不從頭覆蓋。

可用以下工具在工作目錄建立本集設定、素材清單與全數待驗的報告；不修改媒體或剪映：

```text
python scripts/init_episode.py --episode 159 --media-dir "<MEDIA_ROOT>\PODCAST\01-已播出\159" --work-dir "<本集工作目錄>" --probe
```

工具中的159只是命令示例，改成本次集數。補齊產生的 `episode-config.json` 的A/B/錄音、正式起訖、標題和最新草稿快照後才編輯。

## 操作原則

- **背景執行**：不操作前景視窗、不移動滑鼠、不自行關閉程式；Windows子程序隱藏執行並設低優先權。依實際CPU/GPU與工作負載控制併行，不把高占用當作背景不干擾。只有必需且未取得資訊時才集中詢問。
- **保護草稿**：原生讀寫用可用的 `capcut-edit` 技能；先診斷實際剪映版本與加密／Timelines結構。寫入前備份、確認草稿已離開編輯頁、再比對目前版本。若正在編輯，只繼續分析／副本製作，等安全時機寫入，不能關閉使用者程式或強制覆寫。輸出後還要比對最新草稿的渲染相關內容。
- **一份時間線**：從最新有效草稿產生不可變的本集快照；影像、音訊、SRT、諮商室時點、YT時間戳共用同一個時間基準。先檢查該快照與原生內容一致，後續修改必須使受影響快取及驗收失效。
- **CC字幕**：完成帶不燒錄逐字字幕，MP4也不內嵌字幕資料流。草稿的SRT軌隱藏，獨立交付UTF-8繁體SRT；底BAR、提問卡、Logo及指定廣告原有宣傳文字照常保留。
- **不虛報完成**：軌道正常、格式正確、單張預覽或檔案存在，都不能代替實際成品檢查。記錄實際輸出方式，不冒稱FFmpeg成品為剪映原生匯出。

## 執行順序

1. **盤點與同步**：讀 [剪映製作](references/production.md)。核對A、全部B分檔及獨立錄音，用原音波形和有效時間碼建立同步與長錄影飄移模型；保留B各檔的原始來源，不必先重壓成一支。
2. **組裝本集草稿**：V1=A（兩千）在右、V2=B在左、A1=主錄音。關閉A/B原音，以A為準調B曝光，套適合本集的裁切、遮罩與羽化。保留正式節目開頭／結尾音樂，前加指定廣告、後加指定片尾。
3. **字幕、底BAR與主題**：轉錄正式節目，排除外加片頭片尾；使用 `txttosrt` 做繁體校正與時間碼驗證，沿用已確認詞。讀完完整最終SRT後決定本集主題，按正確底BAR PSD更新集數與標題。疑點先聽原音，仍不明才集中詢問；不憑猜測改人名。
4. **諮商室**：依本集SRT和進場音樂製作「我的預設24」諮商室，更新全部提問，題數不固定。核對時點、圖層、動畫、長題換行及前後投稿卡後，固定輸出快照。
5. **輸出實際影音**：讀 [背景輸出與續跑](references/rendering.md)。使用者已接受依同一份剪映時間線以FFmpeg背景輸出，再驗收實際成品。先驗證短段的構圖、遮罩、調色、動畫與文字等效；遇到不能忠實重現的效果先解決，不用近似結果冒充通過。MP4與MP3來自同一份完整帶聲音母帶。
6. **完整帶100%門檻**：讀 [25項驗收與報告格式](references/acceptance.md)，檢查實際成片並保存證據。全部必要項目通過才進入封面，不能只把JSON狀態改成pass。以工具核對版本及證據：

   ```text
   python scripts/check_gate.py "<本集完整性檢查.json>"
   ```

7. **封面與YT資訊**：門檻通過後，直接執行 [封面與YT交付](references/cover-youtube.md)，不再詢問要不要做封面。從本集原始影片擷取兩人個人獨照，去背／加亮／校色，使用指定封面PSD的本集副本；依完整SRT製作YT標題、精華時間戳記、hashtag。
8. **交付驗證**：核對最終MP4、MP3、封面、YT資訊及CC檔，保存檔名、規格、來源版本、大小及SHA256。封面另核對原尺寸與320×180縮圖。最後附可點擊的絕對路徑及簡潔驗收結果，不自行上傳／發布。

## 100%的意義

第24項「完整逐字稿逐句聽校」預設為必要門檻；只有本次使用者明確豁免時才記為 waived 並保留依據。其他24項仍須全部通過。不能把豁免冒稱已聽校，也不能將驗收率說成畫素相似率或字幕正確率。

影片驗收通過後才開始本集封面；封面本身仍須檢查，不能因影片100%就跳過封面品質。草稿或素材版本改變，先重做受影響檢查再交付。

## 固定交付

本集資料夾內交付：

- `EP<集數>.mp4`：含廣告與片尾的完整帶，無燒錄逐字字幕。
- `EP<集數>.mp3`：同一完整帶聲音。
- `EP<集數>.png`：YouTube封面，不能拿底BAR圖片充當封面。
- `EP<集數>_YT資訊.txt`：本集標題、說明、精華時間戳記、hashtag。
- `EP<集數>.srt`：獨立YouTube CC字幕。

保存 `<集數>_完整性檢查.json`、可讀報告與 `EP<集數>_交付清單.json`；封面來源獨照、編修提示詞及PSD副本另存素材子資料夾。重跑輸出先用暫存檔，驗證後再發佈到指定檔名；已有成品先辨識版本，不盲目覆蓋。
