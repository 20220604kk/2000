# /2000yt 封面

依兩千／2000CAR 既有頻道視覺，製作或審閱一般 YouTube 影片封面。接受 `/2000yt 封面`、`/2000 yt 封面`、`/2000yt thumbnail`、`/2000yt cover`。Podcast 不沿用這套標準，除非使用者明確指定。

## 使用順序

1. 讀取 [封面製作標準](references/production-standard.md)。若已提供標題、逐字稿、人物照、車照或母版，直接沿用，不重問既有資料。
2. 按主題選版型，再從 [22 張封面觀察索引](references/cover-observations.md) 挑 2～3 張相近範例，實際開圖檢視；不要只按範例標題猜版面。圖片在本流程 `references/samples/`，不依賴原下載資料夾仍存在。
3. 將影片承諾整理成「主標＋補充／反差＋必要車型或價格」。與影片標題一起檢查；車名、年份、關鍵數字可重複，完整標題不要原封不動貼滿封面。
4. 使用者只要文案／規格／標準時，交付相應內容。要求製作成品且素材足夠時，直接製作並檢視成品；只有必要的照片、母版或資訊缺失才詢問。能從已授權的本地影片取得適合畫面時，先檢查影片，不把「沒有另外上傳照片」當作缺素材。
5. 有既有 PSD／可編輯母版，優先保留圖層與精確文字。需要生成或編修點陣素材時，使用當前可用的 imagegen 技能與工具；純 HTML／SVG／程式排版以相應工具實作。不要為了遵守版型而虛構車型、改裝、事故畫面或價格。
6. 交付前看 1280×720 全圖及 320×180 縮圖，必要時加看 160×90；實際檢查主標、車頭、人物臉、車型對應及右下時間標記區。交付成品前檢查文字與本次影片事實。

## 交付

- 文案／設計稿：推薦版型、主標與副標逐字稿、人物／車輛位置、參考圖 ID、素材缺口（若有）。已有素材的製作請求不止於設計稿。
- 成品：封面 JPG／PNG；可用時附可編輯母檔與縮小預覽，列出實際輸出尺寸。遵守使用者指定格式與命名。
- 審閱／改稿：指出具體的字、位置與遮擋問題，保留使用者確認的視覺方向。

本流程的版型、像素與字數是品牌製作起點，不是 CTR 保證。未取得官方字型或 PSD 時，不宣稱已還原原始字型、圖層、描邊參數。不得把「製作封面」解讀成更新 YouTube 或公開發布。
