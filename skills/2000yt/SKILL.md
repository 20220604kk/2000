# /2000yt

屬於 2000 skills 系統的 YouTube 入口。讀取 [YouTube 流程](../2000/workflows/2000yt/WORKFLOW.md)，再按需求載入一個子流程。明確要求「封面／封面製作」時載入封面流程；只要標題或縮圖文案則走標題流程。未指定子功能但已有主題／標題時，預設產出標題與縮圖配對。

接受 `$2000yt`、對話中的 `/2000yt <功能>` 及 `/2000 yt <功能>`。這些是技能調用與對話入口，不宣稱已新增宿主原生 slash command。舊 yt-* 名稱由共用流程映射。
